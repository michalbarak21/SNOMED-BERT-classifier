# and only the tags those lists use. Every rule is [PREN], i.e. forward-scoping,
# which is the claim these cues make: the trigger is stated before the symptom it
# brings on. The same subordinator standing after the symptom usually reports
# relief instead ("it settles after I sit down"), and a forward rule cannot reach
# back to it.
